# Popout Events — Event Creation Web Application

Popout Events is a web application that provides a multi-step process for creating and configuring events.

Users can enter event details, upload an event flyer, specify dates and locations, add social links, configure ticket options, and preview the event before submission.

## 🌐 Live Demo

https://popout-events.infinityfreeapp.com/

## ✨ Features

* Multi-step event creation process
* Event flyer upload
* Event name and description
* Event category selection
* Start and end date configuration
* Event location with map preview
* Social media links
* Ticket configuration
* Ticket quantity and pricing
* Service fee calculation
* Buyer/organizer fee selection
* Event preview before submission
* Database-backed event submission

## 🛠️ Technologies

* HTML
* CSS
* JavaScript
* PHP
* MySQL
